# Deferred

Agent-maintained. Work deliberately **not** done now, mirrored here from the
`## Deferred / Follow-ups` section of each spec so it is not lost when the spec
is finished and filed away.

The agent appends here. Promotion is the user's call: when the time is right the
user moves an item into `docs/TODO.md` (or it becomes a feature spec of its own),
and the agent then removes it from this list.

One line per item: `- <what> — from docs/spec/<file>.md (YYYY-MM-DD)`
